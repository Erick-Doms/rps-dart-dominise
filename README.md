Rock, Paper, Scissors (Dart)

A two-player, console-based Rock, Paper, Scissors game written in Dart.

Name: Erick Xander L. Dominise
Course / Section: IT 120 - ILGX3

How to Run

Run it in a terminal or command prompt (DartPad does not support console input):

run this -> dart rock_paper_scissors.dart


How to Play
1. Both players enter their names (blank names default to "Player 1" and "Player 2").
2. Player 1 types a move (rock, paper, or scissors). The screen is then cleared with blank lines so Player 2 cannot see it.
3. Player 2 types a move.
4. The round winner and current scores are shown.
5. Type n when asked to play another round to quit and see the overall winner.
